# 当前产品定版 — Look to Ask 0.4.5

**Look at anything, ask anything.** 当前交付是 Windows 10/11 x64 桌面 MVP，本地安装包，尚未公开发布。
用户已确认当前 EyeTrax 跟踪与 GPU 语音体验满足使用；这不是所有设备上的精度或兼容性保证。

## 现在包含什么

- EyeTrax / MediaPipe 本地眼动追踪；默认九点校准，可重新校准、独立测量精度；注视标记跟随并在丢失/越界时隐藏。
- 按钮选择与刷新摄像头；支持 640×480、1280×720、1920×1080，检查实际采集尺寸，切换后重校准。
- Ctrl+Alt+A 冻结注视位置，隐藏自身窗口后截图；预览注视附近裁剪，输入文字并确认发送。
- Ctrl+Alt+V 或 Ctrl+Alt+Space 按住说话；开始时锁定稳定注视区域，松开关闭麦克风、本地转写并自动发送。
- faster-whisper 默认 medium / 中文 / beam=5；可选 NVIDIA GPU 加速，失败回退 CPU；可改 small/base 或本地模型。
- 可配置 OpenAI 兼容多模态 API、悬浮回答、录音/识别/请求状态、取消、停止摄像头和退出。
- 非敏感设置保存在本机；API Key 默认仅内存，主动选择记住时使用 Windows 凭据管理器。
- 主窗口「Language / 语言」支持跟随系统、简体中文、English；选择立即保存，退出重开生效。新装跟随系统，旧配置保留中文；与语音识别语言分开。
- Windows 当前用户安装、开始菜单入口与卸载；便携 ZIP 可直接解压运行。

## 窗口与操作

主窗口提供界面语言、摄像头、开始/重新校准、截图提问、API/语音设置、准备语音模型、按住说话、状态、停止和退出。
高级选项保留校准点数、分辨率、独立精度测量与快捷键自检；不再提供替代眼动引擎或双模型比较。
回答窗口显示本次裁剪、原始问题/转写和 AI 答案。文字模式确认发送；语音模式松开后自动发送。

一次正常使用：启动 → 选摄像头 → 配置 API → 校准 → 准备语音模型 → 注视目标并按住说话 → 松开 → 查看回答。
退出或停止摄像头后不保留个人校准；下次重新校准。
切到英文界面不会把普通话识别改为英文，也不会改写原始问题、转写或回答。切换语言不访问密钥库；仅内存的 API Key 在重启后需重新输入。

## 保留的边界

摄像头与语音本地处理；麦克风只在按住期间开启。截图只由用户主动触发，发送局部裁剪，不发送整屏。
音频、截图、问题、答案和个人校准不落盘；诊断日志仅内存元数据，不包含内容或密钥。
通用模型缓存和非敏感设置属于本地正常运行数据，与私人录制数据不同。

当前只支持主屏。普通摄像头有误差、依赖坐姿和光线；校准拟合残差不等于独立精度。
真实 AI 回答需联网与用户的模型 API。Windows 11 是开发/打包平台，干净 Windows 10 仍待测试。
