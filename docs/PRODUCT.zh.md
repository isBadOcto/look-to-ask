# 当前产品范围 — Look to Ask 0.5.0

**Look at anything, ask anything.** Windows 10/11 x64、普通摄像头、EyeTrax 唯一眼动方案；不训练新模型。

## 两种发送目标

- **原多模态 API 模式**：Ctrl+Alt+A 主动截取注视附近双图、文字预览确认后发送；按住 Ctrl+Alt+V / Space 说话，松开后自动发送冻结局部截图和本地转写。可配置 OpenAI 兼容 API，悬浮窗口显示回答。
- **Codex 桌面对话模式**：用户绑定本机 Codex 专用对话链接。按下冻结最近真实注视点的中位数，不以普通抖动拒绝提问，主动截图一次，生成整张主屏概览及同帧注视局部原像素图；松开关闭麦克风，本地识别后自动入队。概览标出局部图范围和注视位置，目标不会随录音中的眼睛移动改变。回答在 Codex 查看，不需要模型 API Key。

Codex 模式用桌面版自己的本地图片队列，不模拟粘贴、不改动已有草稿、不创建独立生成回答的 CLI 会话。Codex 忙时排到其后续队列。入队不能从本应用撤回；状态不确定时先检查目标对话，不自动重发。此适配与桌面版协议相关，现阶段只支持实测版本；其他 GPT/AI 客户端仍未接入。

## 后台体验

主窗口只是配置/维护入口，配置、校准和准备语音后最小化到托盘。后台语音不恢复主窗口、预览或注视标记。托盘可打开设置、重新校准、停止摄像头和退出，悬停查看状态。无系统托盘时保留任务栏入口，避免应用消失后无法找回。

不增加通知、不读取或监测 Codex 回答；使用用户客户端自己的提醒。其后台提醒和点击行为仍需在用户设备实际验收。

## 保留能力

- 校准九点/25点、独立精度测量、真实 640×480 / 720p / 1080p 采集选择；切换需重校准。
- faster-whisper 默认 medium/中文/beam=5，NVIDIA GPU 可用时优先，否则 CPU；录音仅按住期间，最多30秒。
- 简体中文/English/跟随系统，界面语言与识别语言独立；原始转写不改词。
- 设置保存 LocalAppData，API Key 默认内存；主动记住时仅使用 Windows 凭据管理器。
- Windows 当前用户安装/便携包、许可入口、源代码与 LGPL 对应源码侧包。

## 隐私与限制

摄像头本地；音频、个人校准、截图不由本应用落盘，不持续截屏或上传。Codex 模式的两张 PNG 以内存 data URI 交接，**Codex 自己会保存队列及聊天附件/历史**。该模式会发送整张主屏，包括当时可见的应用和桌面；界面明确说明此范围。

当前只支持已校准主屏。按用户要求直接截取主屏，不再判断应用/窗口或拒绝重叠；仅保留注视新鲜度与 DPI 校验。屏幕之外的内容不自动滚动采集。普通摄像头坐标近似，需稳定坐姿和光线，独立精度不能由拟合残差替代。

校准在内存，最小化后保留，完全退出重启仍需重做。语音模型下载/原生推理不能强制中断，取消后丢弃迟到结果；退出等待其安全结束。干净 Windows10、真实硬件精度与原生通知需人工测试。
