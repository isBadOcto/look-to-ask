## 安装后完成一次真实问答

1. 关闭旧程序。安装 `dist/LookToAsk-0.4.5-Setup.exe`，从开始菜单启动；无需 Python/管理员权限。
   便携版须完整解压整个 ZIP 后运行，不能只移动 exe。
2. 启动时摄像头/麦克风不应开启。选择摄像头，插拔后可刷新；检查快捷键注册状态。
   在顶部「Language / 语言」选择 English，退出重开；应显示英文控件/隐私/状态。再选简体中文并重开，检查恢复中文。
   语言切换应保持摄像头/API/语音设置；普通话识别仍是中文。仅内存的 API Key 重启后需重新输入，这是既有设计。
3. 在「API / 语音设置」填写图片模型、API 地址和 key。默认不记住 key；只有主动勾选记住才存 Windows 凭据管理器。
4. 完成九点校准。保持坐姿稳定，注视标记应跟随；丢失/眨眼/越界时隐藏。停止后可换分辨率或摄像头并重校准。
5. 打开安装目录 `_internal/demo/targets.html`，主屏浏览器 F11。看左上对象，按 Ctrl+Alt+A；
   预览应对应目标，且无自身窗口/注视标记残影。输入「读出注视对象的名称和编号」并发送。
6. 对中心、右下重复。AI 应回答预览内的目标；定位不清应说明不确定，不能只猜整屏。
7. 语音选择 medium / 中文，保存并准备。当前配置好 NVIDIA 运行库的电脑应显示 GPU 加速，否则显示 CPU。
   稳定注视左上约半秒，按住 Ctrl+Alt+V，见录音提示后说话；录音中移开眼睛再松开，裁剪目标仍应是起始区域。
8. 连续问三个不同区域，检查转写、裁剪和新请求。取消一次后再问，旧答案/转写不能覆盖新问题。
9. 重校准、停止摄像头、退出时麦克风应立即关闭；退出后设备应能被其他程序使用。
10. 如需定量检查，在高级区执行独立精度测量，记录中心/周边/越界比例；不能用校准内残差代替。

验收通过的依据是实际装好、校准、完成一次文字与三轮语音问答，并确认目标锁定和退出正常。
程序不自动保存截图/录音/个人校准；可复制内存诊断元数据，不要提供密钥或私人录音。

## DPI 与错误路径

- 在 100%、125%、150% 缩放分别重启/校准，检查中心和边缘的预览对象一致；显示设置变化后须重启。
- 拔掉摄像头/麦克风、拒绝权限、松开太快、静音、超时、无稳定注视和错误 API 设置，应给出可恢复提示。
- 断网/无效模型/401/429 时，不应泄漏密钥、模型私有路径或提供商响应内容。
- 独立测量取消后原校准仍有效；重新校准取消后应要求再次校准。
